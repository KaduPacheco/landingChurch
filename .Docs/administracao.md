# Administração (usuário)

## Quem pode usar

Administradores da igreja; ROOT para operações de plataforma.

## O que faz

- Dados da igreja e congregações
- Cargos, funções e perfis de permissão
- Usuários administrativos
- Planos / onboarding SaaS (quando aplicável)

## Cuidados

- Alterar permissões impacta imediatamente o acesso às telas.
- Usuário ROOT não deve ser usado no dia a dia da igreja.
