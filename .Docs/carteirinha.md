# Carteirinha (usuário)

## Quem pode usar

Administração / secretaria com permissão de carteirinha.

## O que faz

Configuração de layout e emissão/validação de carteirinhas de membros.

## Passo a passo (visão geral)

1. Configure o layout em carteirinha (se disponível no menu).
2. Emitir/imprimir para o membro selecionado.
3. Validação pública usa a rota de validação (QR/código), quando habilitada.

> Fonte: `carteirinhalayout/**`, rotas `validar-carteirinha`.
