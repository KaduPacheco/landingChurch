# Financeiro (usuário)

## Quem pode usar

Perfis com permissão financeira.

## O que faz

Controle de caixa, lançamentos, balancetes e prestação de contas por congregação/igreja.

## Passo a passo (lançamento)

1. Abra **Financeiro**.
2. Confirme o caixa aberto (ou abra o caixa, se tiver permissão).
3. Registre entrada/saída com categoria e valor.
4. Salve e confira no extrato/relatório.

## Cuidados

- Não misturar congregações.
- Fechamento de caixa é operação sensível — confirme totais.

> Fonte: `financeiro/**`. Detalhar balancete/prestação quando o fluxo de UI for alterado.
